# 纯图文模式详情

> SKILL.md 的指针文件。当用户指定"公众号""图文""推文"任一关键词时激活本模式。

## 模式识别与分流

- 用户指定"公众号""图文""推文"任一关键词时，自动激活纯图文模式。
- 纯图文模式下，全流程不出现任何视频参数（时长、画面比例、分辨率、分镜、运镜、口播音色、BGM、字幕样式等）。
- 纯图文模式是快速流：确认单 → 交付 → 发布前质检；但 `quality/check_article.py` 与《综合质检表》必须通过。
- 选配参数统一引用 `references/shared-config.md` 的【共用选配确认单】，本文件不再重复维护参数清单。

## 图文专属交付结构

1. 【本次图文设定卡】：主题、字数、风格、受众、排版。
2. 爆款标题：提供 3 个备选，分别为悬念型、共鸣型、干货型。
3. 摘要：120 字以内，制造点击欲。
4. 公众号正文：使用 Markdown 排版；短段落、关键句加粗、至少 2-3 句金句、段间有呼吸停顿。
5. 配图建议：用文字说明每个位置配什么图（风格、主体、情绪），替代视频分镜；正式发布前按配图师规则落盘到 `images/`。
6. 投后数据回收指令：输出一行可复制的 `@投放数据` 模板。

## 投后数据闭环（图文版）

- 用户输入 `@投放数据 阅读量=5000 点赞=300 在看=50 转发=20` 这类图文数据时，进行图文复盘。
- 复盘前必须先计算量化指标，不得只凭感觉判断高低：
  - 阅读量低：当前阅读量 < 近 5 篇平均阅读量 × 30%。
  - 转发率高：转发量 / 阅读量 > 2%。
  - 推荐量低：推荐量 / 阅读量 < 10%。
  - 在看/转发互动低：在看量与转发量合计 < 5。
- 用户没有提供近 5 篇平均阅读量时，先索要基线数据；无法获得基线时只输出绝对指标，不判定"低"，并标注"缺基线"。
- 阅读量低但转发率高：标题不够吸引人，但内容有干货；下轮重点优化标题。
- 阅读量高但在看/转发互动低：标题党成功，但内容缺乏共情；下轮重点强化结尾情绪。
- 推荐量低：选题或账号推荐权重不足；下轮优化选题人群匹配、封面关键词和摘要。
- 复盘结论写入本次交付的「下轮优化重点」，并与 `references/private/topic-bank/index.md` 联动。
