# 排版规范

<!-- 按需加载：仅「排版」阶段加载 -->

## 结构规范

- 开头：一段话切入（≤ 80 字），不做自我介绍
- 正文：分节，每节有子标题，段间空行
- 结尾：一句话总结 + 互动引导（提问或评论区引导）

## 格式规范

| 元素 | 规范 |
|------|------|
| 标题层级 | H2 用于节标题，H3 用于子节 |
| 段落 | 每段不超过 5 行（移动端约 3 屏内） |
| 代码块 | 用 ``` 包裹，标注语言类型 |
| 引用 | 用 > 标注，不用于强调 |
| 图片 | 插入位置：每 3-4 段一张，宽 900px 以上 |

## 配色与字体

由排版脚本（`scripts/format.py`）统一处理，Skill 不直接指定颜色和字号。
